Ce este un accordion?

Un accordion este un element de interfață care permite afișarea și ascunderea conținutului prin extindere și contractare. Este folosit frecvent pentru a organiza informații într-un mod compact și ușor de navigat.

Un accordion este un element de interfață care permite afișarea și ascunderea conținutului prin extindere și contractare. Este folosit frecvent pentru a organiza informații într-un mod compact și ușor de navigat.

Cum se folosește?

Pentru a folosi acest accordion, apasă pe oricare dintre titlurile secțiunilor. Conținutul se va deschide sau închide cu o tranziție fluidă. Poți deschide mai multe secțiuni simultan, fiecare funcționând independent.

Pot personaliza stilurile?

Da! Stilurile pot fi modificate cu ușurință în secțiunea CSS. Poți schimba culorile, fonturile, padding-ul și tranzițiile. Iconițele SVG folosesc stroke-uri care pot fi colorate modificând valorile stroke din URL-urile codificate.

Este accesibil?

Absolut! Accordionul include suport pentru tastatură (Enter/Space) și atribute ARIA pentru cititoarele de ecran. De asemenea, are un contrast bun și focus vizibil pentru utilizatorii care navighează cu tastatura.

Cum schimb culoarea iconiței?

Iconițele sunt implementate ca SVG-uri inline în background-image prin pseudo-clasa ::after. Pentru a schimba culoarea, modifică valorile stroke din URL-urile codificate. De exemplu, pentru iconița închisă, stroke=%236b7280 reprezintă gri, iar pentru cea deschisă, stroke=%232563eb reprezintă albastru.
